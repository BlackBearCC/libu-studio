# 模型选择

**用户主导，skill 不锁定默认**。skill 只维护常用清单和适用场景。生成前必须把 **模型 + 分辨率 + 时长（如适用）+ 积分** 四项一起贴给用户确认才点生成。

## 图片模型（图生图洗参考 / 文生立绘）

入口：`/ai-tool/image-generator` → 底部 tab 「图片生成」

| 模型 | 描述 | 典型用法 |
|---|---|---|
| **Seedream 5.0 Lite** | 指令响应更精准，超清 4K，多参考图（便宜，常用 ~4 积分/张） | 默认推荐：洗参考图、批量出候选立绘 |
| 基础模型 F.1 | 经典生图模型，支持挂用户 LoRA（**风格模型**） | 想用 "F.1 卡通手账" 等用户 LoRA 时必走 |
| Qwen-Image / Qwen-Edit | 文生图 / 文字改图，支持风格模型 | LoRA 备选底模 |
| 图片编辑模型 | 局部精准改图，支持风格模型 | 改局部细节 |
| Seedream 4.5 / 4.6 | 多角色超强一致性，多图融合 | 多角色互动场景 |
| 全能图片模型V2-Flash | 联网搜索 + 文字准确 + 速度更快 | 需要文字内容时 |
| Z-image Turbo / Seedream 3.0 | 极速 | 大批量草图阶段 |
| 智能图片V2 | 最新最强（贵） | 单张高质量定稿 |
| 基础算法 F.2 Pro / Flex | 新一代生图与编辑（2K） | 老底备选 |

> **"风格模型" 是能力标签不是模型本身** —— 表示该底模能挂用户训练的 LoRA。能挂 LoRA 的图像底模目前是：基础模型 F.1 / Qwen-Image / Qwen-Edit / 图片编辑模型。要用风格 LoRA 时必须先选其中一个底模，再在面板里加载具体 LoRA。
