# 阶段 A.pre — (可选) 图生图洗参考图

适用：现有绿幕参考表情/姿势不太理想，想先用图像模型改造一版再喂给视频/动作模仿。

1. `browser_navigate("https://www.liblib.art/ai-tool/image-generator")`
2. 底部 segmented tab 选 **「图片生成」**
3. 点底部模型名（默认是 `智能图片V2`）打开「选择模型」弹窗，**按用户指定挑**（不指定就提议 Seedream 5.0 Lite）。模型清单见 [models.md](models.md)
4. 如果用户要套 LoRA：先选 `基础模型 F.1`（或 Qwen-Image / Qwen-Edit / 图片编辑模型），再在面板里加载具体 LoRA
5. 上传当前绿幕参考图 + 写指令（图生图模式）：
   - 例："保持角色和构图不变，把姿势改为双手插兜、头微微歪向左侧。纯绿色背景不变。"
   - **保持绿幕背景**：指令里明确"纯绿色背景不变"，否则模型会换背景
6. 选比例（与原图一致，1:1 / 3:4 / 4:3）和张数（默认 4 张，可调到 1 节省积分）
7. **把模型名 / 张数 / 比例 / 积分四项贴给用户确认**，等"go"才点生成
8. 生成完用户选定一张，下载保存到本地，作为下一阶段（A 或 A.alt）的输入参考图

注意：图生图本质是新一次生成，每次都扣积分。多次迭代会累积，先把指令写准再点。

## 入库

该次生成的 4 候选 + 用户选定记录应作为一条 `generations` 行（`stage='a-pre'`，`path='image-refine'`）落到 lab.db，候选挂 `candidates` 表，详见 [archive-compress.md](archive-compress.md)。
