# 阶段 A.alt — Liblib 文生视频（自由生成）

适用：没有现成动作参考，纯靠想象生成新 idle。

**生成前必须让用户确认模型 + 参数 + 积分**（每次按模型计费，跑前 UI 底部那个数字为准）。模型清单见 [models.md](models.md)。

1. `browser_navigate("https://www.liblib.art/ai-tool/image-generator")`（底部切「视频生成」tab）或 `/ai-tool/video-generator`
2. 点 **+图片**，让用户说"第几张绿幕"挑参考图，**不要自己猜**
3. 模型选择：**点底部模型名打开「选择模型」按用户指定挑** — 常用 `Seedance 1.5 Pro`，更稳但贵的备选 `Seedance 2.0 Fast VIP` / `可灵 3.0`。规格面板按用户需求：智能比例 / 720p / 5s / 无配音（典型 20 积分）
4. 尾帧：若要循环回到原位，选**同一张**参考图作尾帧
5. 写 prompt — 必须包含的约束：
   - `纯绿色背景不变`
   - `角色和 [特效] 始终在画面内不超出边缘`
   - `镜头完全固定不动`
   - `身体整体保持静止不晃动`（避免与已有 breathing 动画叠加）
   - `五官发型一致`
6. **把模型 + prompt + 比例 + 时长 + 积分一起贴给用户确认**，等"go/开始"才点生成
7. 监控 "0/1 生成中..." → "1/1 生成完成"（通常 1-3 分钟）
8. 取视频 URL：
   ```js
   Array.from(document.querySelectorAll('video')).map(v => v.src || v.querySelector('source')?.src).filter(Boolean)
   ```
   新增的是列表末尾那条（对比历史，或比较两次 snapshot 的差异）
9. 下载 mp4（必带 Referer 防盗链）：
   ```bash
   curl -sSL -H "Referer: https://www.liblib.art/" -o ~/Downloads/<slug>-<name>.mp4 "<url>"
   ```

## Prompt 写法 — 三条致命铁律

**铁律 1：不要写"第 X 秒"时间戳**。Seedance 不是时间轴动画工具，硬塞秒数 token 会让它去算镜头切换，结果就是中段莫名其妙拉近成特写、再拉远时角色重绘脱锚。改用自然顺序词：`起初 / 接着 / 然后 / 最后`。

**铁律 2：不要描述角色外观**。角色身份 100% 靠首尾帧参考图锚定。在 prompt 里再写一遍"白发、半眯眼、红领带、双手插兜"等五官/服装细节，模型会把"参考图脸"和"prompt 字面意思"做插值；中间帧重绘时一脱锚，就可能直接换成另一个完全不同的角色（实测：写"半眯眼+捏头发"后，第 90 帧整个人变成黑发红头巾忍者）。

**铁律 3：不要描述头发/呆毛/裙摆等次级部件的运动**。一旦在 prompt 里指明"呆毛猛地往上飘"、"头发飞扬"、"裙子扬起" 之类的次级运动，模型会把它当主要动作放飞自由发挥：实测写"呆毛猛地往上飘起来又落下，呆毛持续小幅飘动" 后，呆毛被拉成一道直冲天顶的白色拖影线，第 90 帧甚至蜷成一个完整的问号 "?" 形状。**只描述主体动作（头/手/脖子/身体/姿势），头发跟着主体动就够了**。要表现"动漫感"就用"猛地/一甩/一震/一倒"这种修饰主体动作的词，不要描述发丝。

### 允许写 / 应该写

- 主体动作本身："抬左手、放下、脖子向上一仰、把头甩回正面"
- 气质修饰副词（**按角色设定走**，见 references/characters/<slug>.md）："懒洋洋地"、"漫不经心地"、"慵懒"——这些修饰动作而非外观
- 核心约束词（每条 prompt 末尾必带）：`身体整体保持静止不晃动`、`五官发型一致`、`眼神不变`、`角色始终在画面内不超出边缘`、`镜头完全固定不动`、`纯绿色背景不变`

### 禁写

- ❌ "第 X-Y 秒…"、"5 秒后回到初始" 之类的时间戳
- ❌ "白发"、"蓝眼睛"、"红领带"、"百褶裙" 等外观描述
- ❌ "半眯眼"、"嘴小" 这种五官静态描述（动作描述里写"眼皮慢慢垂下"是 OK 的，描述当前形态不行）
- ❌ "呆毛飘起"、"头发飞扬"、"发丝抖动"、"裙摆扬起" 等次级部件主动运动
- ❌ "镜头特写"、"拉近"、"放大" 等任何镜头运动暗示——会触发模型做镜头切换

### Prompt 模板

> 角色原地待机。起初 [初始姿态/状态]。接着 [动作 A]，[气质修饰副词]。然后 [动作 B]。最后恢复初始姿态。身体整体保持静止不晃动，五官发型一致，眼神不变，角色始终在画面内不超出边缘，镜头完全固定不动，纯绿色背景不变。

参考既有成功 prompt 的句式 —— 直接从 lab.db 查同角色历史成功 prompt 照抄结构：
```bash
sqlite3 <lab-root>/lab.db \
  "SELECT t.name, g.prompt FROM generations g
   JOIN anim_tasks t ON g.task_id=t.id
   WHERE t.character_slug='<slug>' AND g.chosen=1
   ORDER BY t.id;"
```
